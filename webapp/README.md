# Interface Vase Honneur

Consulter ../README.md pour l’installation et la mise en service.

React 18, Vite et Lucide. `npm run dev` ouvre l’interface sur le port 5173. `npm run build` produit dist. `npm run lint` vérifie le code. `npm run format` met en forme les sources. L’interface utilise /api via le proxy de développement ou une URL VITE_API_URL définie avant compilation. Les contenus viennent de MySQL ; aucune donnée de l’ancien projet ICC n’est utilisée.
